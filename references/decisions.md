# 决策记录

记录每个默认值为什么是现在这样，尤其是 Jim 过往项目之间意见不一的地方。以后要改某个默认值，先看这里。

格式：决策 · 理由 · 来源 · 日期。

## 2026-11-01 · 0.1.0 初版

调研了 Jim 过往的四个产品项目（后台、移动端、商城、工具）。点名的只有开源的 greenhouse（web + 历史上的 Native Haven v2 规范），其余写作「其他项目」。

| 决策 | 理由 | 被放弃的方案 |
| --- | --- | --- |
| 默认纯中性灰加黑色强调色 | Jim 要的是 Notion 式的黑白；四个项目都是「中性色 + 一个强调色」的结构，只是颜色不同 | 绿色系中性色 |
| 语义名沿用 shadcn，另加少量扩展 | 能直接用 shadcn 生态的组件；Jim 各项目自造的名字（surface / fg / edge）互不兼容 | greenhouse 的 `--t-*`、其他项目带品牌前缀的变量 |
| 字体用 Inter + 苹方 | 中性，接近 Notion；Nunito 偏圆润、有品牌感 | Nunito（三个项目在用，可以通过 `--font-sans` 换回） |
| 正文 14 / 22，最小 12 | 应用界面的密度；greenhouse 的守卫规定过 12px 下限 | 移动端项目的 16px 正文（移动端到第三期再定） |
| 控件 28 / 32 / 40，触屏 ≥ 44 | 桌面端偏 Notion / Linear 的密度，触屏端满足 44；用 `pointer: coarse` 判断，不靠断点 | greenhouse 的 36 默认、移动端项目的 52 |
| 圆角 8 基准，按比例缩放 | 四个项目的交集：按钮和输入框 8，卡片 12，弹框 16，底部弹层 24 | 移动端项目的 16 卡片 |
| 卡片扁平，只有两级阴影 | 四个项目都这么规定 | — |
| Toast 放顶部居中、叠放；浮层底，级别只靠图标颜色，错误加淡红底；4s / 6s / 8s，错误不自动消失 | 2026-11-01 Jim 拍板：位置改到顶部居中（初版右下），要按级别带颜色但不突出；视线自然落点，手机和桌面同一位置；错误自动消失容易被错过 | 右下（初版）、反色无级别色（初版，沿用 greenhouse v2）、右上 3s（greenhouse v1） |
| 错误不用会自动消失的 Toast | greenhouse v2 规定「错误不是 Toast」，移动端项目规定失败要弹 alert；折中的结果是：就地显示，后台错误用不消失的 Toast | 普通 Toast |
| 遮罩不模糊 | greenhouse v2 规定；更克制 | greenhouse v1 给弹框加了模糊 |
| Dialog 480 默认，手机上从底部升起 | 四个项目的取值在 340–512 之间；greenhouse 的 OverlayFrame 在手机上从底部升起 | 340 的居中弹框 |
| Drawer 560 默认，一次一层 | greenhouse 的 CrudDetail 用 520，v2 规定 480–880；后台项目规定只能一层 | 后台项目的 min(78vw, 1120)（太宽，改为 lg 档） |
| 底部弹层：Web 用 vaul；原生 App 用系统 sheet | greenhouse 移动端用系统 sheet；移动端项目因为键盘问题弃用了 gorhom | 自己用 JS 画 sheet |
| 表格不画竖线 | Notion 式；greenhouse v2 规定 | 后台项目的带边框表格 |
| 分页 20 / 50 / 100，并记住选择 | greenhouse 规定 | 后台项目的 10–500 |
| 查看、编辑、新建共用一个抽屉，原位编辑 | 2026-11-01 Jim 拍板：编辑沿用查看的布局，控件直接放开编辑，相对位置不变，理解成本低（初版是编辑另开 Dialog，取自 greenhouse） | 编辑另开 Dialog（初版、greenhouse）、抽屉里换一套表单布局 |
| 侧栏收起后，导航项悬停在右侧显示标签名 | 2026-11-01 Jim 提出；只剩图标时必须能知道是什么 | — |
| 确认框焦点默认在「取消」 | 防止误按回车删掉东西 | — |
| 骨架静态，300ms 后出现，至少保留 600ms | greenhouse 规定不闪光；加载闸门 300 / 600 取自移动端项目 | 闪光骨架 |
| 动效：一条 ease-out(.22, 1, .36, 1)，120 / 200 / 240 | 商城和工具两个项目用同一条曲线；时长取三个项目的交集 | greenhouse 的标准曲线 (.2, 0, 0, 1) |
| 按下缩放 .97 只在触屏上生效 | 移动端和商城都用了；桌面端缩放宽按钮会显得跳 | 全平台缩放 |
| 警告色从 #9a6700 压到 #8a5c00 | 原值在自己的 subtle 底上只有 4.22:1，被守卫抓到 | — |
| 控件边框 `input` 不强制 3:1 | 3:1 的灰边框太重，不像 Notion；靠标签和 ≥ 3:1 的焦点环来识别控件 | 工具项目的 borderStrong ≥ 3:1（如果 Jim 坚持，改 `--input` 即可） |
