# 批注侧栏

知识库、报告、合同审阅这类「选中文字 → 评论 → 回到原文」的场景。

## 交互

- 在正文里选中文字，选区上方出现一条浮动操作条（「批注」，需要时加「建议修改」）；点了以后侧栏里出现一个新草稿，引用选中的原文。
- 侧栏是线程列表：每个线程 = 引用 + 评论 + 回复 + 「解决」；当前页的未解决线程按原文顺序排在前面，已解决的收进「已解决」。
- 点线程跳到原文并高亮；点正文里的高亮，侧栏滚到对应线程。
- 宽屏：右侧栏，宽度沿用 inspector 的 360–520，不盖住正文。窄屏：用 BottomSheet 打开线程，正文不缩。
- 批注用分类色或强调色的浅底高亮，不改正文字色；当前线程的高亮再深一级。

## 锚点

- 锚点存「引用 + 前后各约 40 个字符」，不存 DOM 位置或字符偏移；正文被编辑后按引用重新定位，有多处相同引用时选上下文最吻合的一处。
- 原文里找不到引用了：线程保留，标成「原文已修改」，放在列表最后，不悄悄删掉。
- 引用太短（< 2 个字）或太长（> 1000 字）时不出操作条。
- 标了不参与批注的区域（代码块、界面元素）不能被选为锚点。
