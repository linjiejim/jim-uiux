# 列表筛选

## 布局

`FilterBar`：搜索框（240 宽，手机上占满一行）→ 筛选项 → 「清除」（只在有条件生效时出现）。

## 规则

- 搜索框放在最前面。输入停顿 250ms 后再查询（`useDebouncedValue`）；按 Esc 清空。
- 筛选项 ≤ 4 个，常用的放前面。更多的筛选项收进一个「筛选」按钮，点开是 Popover 或 Drawer sm，按钮上显示已生效的条件数。
- **不藏筛选**：每个生效的条件都要能在筛选栏上看到（「状态：进行中 ✕」）。从图表下钻、从链接带进来的条件也一样。
- 未设置的筛选项用虚线边框加 ⌄；设置后变成实线边框、`selected` 底、显示当前值，后面跟一个 ✕。
- 筛选项是单选的，选项里不放「全部」，用 ✕ 清除。需要多选时，用 Popover 加复选框列表，标签显示「状态：进行中 等 2 项」。
- 布尔值用三态：全部 / 是 / 否（`FilterBoolean`），不用开关。
- 条件写进 URL（query 或 hash），这样筛选后的视图可以分享、刷新后还在、浏览器后退能恢复。用 `replaceState` 写入，不在历史记录里堆积。
- 条件变化时回到第 1 页，并清空勾选。
- 结果为 0 时显示「无匹配」，带「清除筛选」。

## 分面筛选

按多个维度同时筛（类型、标签、上传者、是否已识别……）时，用 `FacetFilter`，放在 FilterBar 里、搜索框后面。gallery「模式 · 分面筛选与媒体网格」是示例。

- 三种分面：`single` 单选、`multi` 多选（复选框列表，弹层不关）、`boolean` 是 / 否。都不放「全部」，用 ✕ 清除。
- 未设置：虚线边框 +「标签 ⌄」。设置后：实线、`selected` 底、「标签：值 ✕」；多选写第一个值加「等 N 项」。
- 分面超过 4 个：前 3 个留在栏上，其余收进「筛选」Popover，按钮上写其中已生效的个数；收进去的分面一旦生效，也作为「标签：值 ✕」出现在栏上。
- 条件写进 URL（`useFacetParams`，每个分面一个参数，多选重复参数），`replaceState` 写入；刷新、分享、后退都能还原。
- 「清除」一次清掉搜索和所有分面。
- 结果为 0 显示「无匹配」+「清除筛选」，不显示成「空」。

## 不要

- 在筛选表单里用占位文字代替标签，或者标必填 `*`。
- 用「应用」按钮。筛选立即生效；只有特别贵的查询才例外，此时用 Drawer，底部放「应用」。
- 把筛选做成一个弹框。
