# 页面布局

讲页面里面放什么：常见页面各自的骨架，写清宽度、间距、什么时候用、用哪些组件。外壳（AppShell、工作台）、三档页面宽度、页头和区块见 `layout.md`。gallery「模式 · 页面布局」有每种骨架的线框图，以及概览、详情页、单卡片页的实际样子。

数值参考了 Primer、Polaris、Material 3、Atlassian、Carbon、Ant Design Pro、shadcn blocks、Stripe Apps 和 Geist 公开的代码与文档（2026-11-23 调研，见 `decisions.md`「1.8.0」）。各家数值不一致的地方，按 kit 已有的刻度取整到 4px。

## 先选骨架

| 页面在做什么 | 骨架 | 页面宽度 |
| --- | --- | --- |
| 看一组指标和趋势 | 概览 | `wide` |
| 管理一类对象（增删改查） | 列表（`list-crud.md`） | `wide`，宽表格用 `full` |
| 对象有自己的标签页、子列表，或者要能用链接打开 | 对象详情页 | `wide` |
| 一条一条处理（收件箱、工单、审核） | 列表-详情分栏 | `full` + `fill` |
| 主要内容，旁边放属性、相关项或帮助 | 主栏 + 侧栏 | `wide` |
| 设置、偏好 | 设置（`settings.md`） | `narrow` |
| 要分几步填完的表单 | 分步表单 | `narrow` |
| 还没有内容、出错、没有权限、找不到 | 空页与结果页 | 跟所在页面 |
| 登录、注册、邀请、授权 | 单卡片页（`entry-pages.md`） | 卡片 400 |
| 画布、编辑器、预览 | 编辑器 | `full`，没有页面内边距 |
| 一组对象按阶段推进 | 看板 | `full` + `fill` |
| 图片、模板、项目卡片 | 卡片网格 | `wide` |

不在表里的页面，先看能不能拆成上面几种的组合；拆不了再新写，并补进本文。

## 通用规则

- 间距：页面内边距 `--space-page`（24，手机上固定 16）；区块之间 `--space-section`（32）；卡片之间、卡片内边距 `--space-card`（16）。`data-spacing` 会把它们一起收紧或放宽（`tokens.md`「间距」），页面里不另写数字。
- 滚动：文档类页面（概览、详情、设置）整页滚动。分栏、编辑器、看板固定在视口高度（`Page fill`），每一栏自己滚动。
- 吸顶：页头不吸顶。表格表头、分栏里的列表头、编辑器工具栏吸顶；宽屏上的侧栏吸顶，顶边对齐页面内边距。
- 主操作放在页头右侧，不放在页面底部。只有长表单的「保存」用底部的 `SaveBar`。
- 两栏看内容区有多宽，不看窗口：`PageColumns` 自己 ≥ 896 才分栏（主栏至少 544）；整页的分栏（列表-详情、编辑器）从 lg（1024）开始。以下一律单栏，不另做平板布局。

## 概览（仪表盘）

页头 → 指标行 → 图表 → 「最近」列表。

- 指标行用 `StatGrid` + `Stat`：手机 1 列，sm 起 2 列，xl 起 4 列。只放一行，最多 4 个，更多的放进详情。数值 28（`text-display`），用等宽数字；统计口径放进 ⓘ。
- 图表放在 `Card` 里：xl 起两列，以下一列。同一行的图一样高（常规 180，主图 320），加载、空、出错时也保持这个高度。一行最多 3 个图，每个不窄于 200。
- 顺序：先指标，再趋势，最后是「最近」列表。列表 ≤ 6 列，末尾链接到完整列表。
- 不做：拖拽自定义布局；每张卡片放一个主按钮；装饰性的大图标和插画。

## 对象详情页

返回 + 标题 + 元信息 + 操作 → 标签页 → 主栏 + 侧栏。

- 什么时候用：对象有自己的标签页或子列表（项目下的任务、成员），或者要能用链接直接打开。只是看和改几个字段的列表对象用抽屉（`list-crud.md`），不单独开页面。工作台里从 inspector「提升到主区」打开的也是这种页面。
- 页头：`PageHeader back` 返回列表；标题是对象名；下面一行元信息（状态 Badge、负责人、更新时间，`text-small` 次要文字色）。主操作最多 1 个，其余收进 ⋯。
- 标签页紧贴页头下方（`Tabs`），≤ 6 个，第一个是「概览」。
- 正文用 `PageColumns`：主栏放内容和子列表；侧栏 320 放属性（`DetailList`，一列）和相关对象；内容区不到 896 时侧栏落到主栏下面。
- 编辑：在侧栏的属性里原位编辑，或打开抽屉。不跳到单独的「编辑页」。

## 列表-详情分栏

列表 360 | 详情。

- 什么时候用：要一条一条处理的队列。只是偶尔看一条，用列表 + 抽屉（`overlays.md`「列表详情」）。
- lg 起两栏：列表默认 360，可以拖到 280–480（`ResizeHandle`，双击复位，按页面记住），中间一条 1px 细线。
- 选中项一直高亮（`bg-selected`）。没有选中时，详情栏显示一句提示（「选择一条查看」），不留空白。
- ↑ / ↓ 或 J / K 在列表里移动，详情跟着换，键位和 `useListPaging` 一样。
- lg 以下单栏：列表占满宽度，点一条进入详情，标题左边有「返回」。窗口变窄时，留在正在看的那一条上。
- 页面用 `full` + `fill`，两栏各自滚动。

## 主栏 + 侧栏

- 用 `PageColumns`：侧栏 320，中间 `--space-section`；内容区 ≥ 896 才分栏，所以主栏至少 544。更窄时侧栏落到主栏下面。
- 侧栏放属性、相关、帮助、目录，不放主操作。
- 宽屏上侧栏吸顶（组件自带）；侧栏比视口高时，跟着页面一起滚。

## 设置

见 `settings.md`。分组超过 6 个时，左边加一列 200 宽的分组导航，正文仍是 `narrow`。

## 分步表单

- 什么时候用：要填 3 组以上，而且后面的选项取决于前面的。一屏能填完的不拆步。
- 宽度 `narrow`，表单列最宽 560。
- 不超过 4 步：步骤条放在顶部（「1 基本信息 · 2 成员 · 3 确认」）。超过 4 步：左边一列 200 宽的步骤列表。步骤名 ≤ 6 个字。
- 底部一行：左边「上一步」（第一步没有）；右边「取消」和「下一步」。最后一步是确认页，主按钮写结果（「创建项目」）。
- 填过的步骤可以点回去改。离开前如果已经填了内容，先确认（`dirty`）。
- 步骤少、内容短，放进 `Dialog fixed`（框不会随步骤跳动）；否则单独一页。

## 空页与结果页

- 区块里的空、无匹配、无权限、出错：用 `StateView`，见 `feedback.md`。
- 整页的（第一次使用、404、无权限、出错）：用 `StateView size="md"`，水平居中，上方留 80，最宽 464。内容是图标、一句标题、最多一行说明、最多一个主操作和一个次要操作。
- 第一次使用：说清这里会出现什么，给一个创建入口，不放长篇教程。筛选后为空时不给「新建」，给「清除筛选」。
- 404 写「找不到这个页面」，配「回到首页」；无权限写明要找谁开通；出错用人话说明，并给「重试」。不显示错误码；给技术支持看的请求编号可以放进 ⓘ。
- 操作完成后，一般不需要结果页：回到列表，新出现的那一行就是结果。只有结果必须单独说明时（付款完成、导入完成）才用结果页：图标、标题、一行说明，「查看」和「返回」两个操作。

## 单卡片页（登录、注册、入口页）

- 规则见 `entry-pages.md`。尺寸：卡片 400，垂直居中；手机上占满宽度，左右各留 16。产品标志在卡片上方，间隔 24；页面四周留 24，md 起 40。
- 控件 44 高，主按钮和卡片一样宽。
- 宽屏上可以分成左右两栏（左边放插图，lg 以下去掉），表单那一栏仍是 400。

## 编辑器与画布

- `full`，没有页面内边距。顶部工具栏 48，吸顶；左右面板 240–320，可以拖到 480，可以收起（`ResizeHandle`），收起状态要记住。
- 画布自己滚动和缩放，页面本身不滚。
- 面板里分组用小标题（`text-small font-medium`），不用卡片。
- 窄屏上面板变成底部弹层（`BottomSheet`）或抽屉。

## 看板

- `full` + `fill`。看板这一块横向滚动（不是整页横滚），每一列自己纵向滚动。
- 列宽固定 288，列间距 12。列头是列名、数量和 ⋯；卡片之间 8。
- 卡片：标题最多 2 行，元信息最多 3 项（负责人、日期、标签）。点卡片打开详情抽屉。可以拖到别的列，也要能用键盘或菜单里的「移到…」完成。
- 窄屏上一次看一列，用 `Segmented` 或 `Tabs` 切换。

## 卡片网格

- 用 `CardGrid`：每列最窄 240，列数自动；间距 `--space-card`。缩略图高度从 180 起，比例用 16:9、4:3 或 1:1，一个网格里只用一种。
- 卡片从上到下是封面、标题（1 行）、元信息（1 行）。整张卡片可以点；操作收进 ⋯（桌面上悬停时出现，触屏上一直显示）。
- 数量很多的（媒体墙）用无限滚动（`feedback.md`），其余分页。
