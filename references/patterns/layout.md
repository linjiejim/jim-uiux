# 布局与导航

## 应用外壳（AppShell）

- 侧栏宽 240，可以收起到 56（只显示图标）。收起状态会被记住，不会因为窗口变窄自动改变。
- 侧栏用 `sunken` 底，右边一条细线。导航项高 30（触屏上 40），图标 16 + 文字 14。
- 当前项：`pressed` 填充 + 全对比文字 + 字重 500。不加竖条、不加强调色、不加描边。
- 分组标题 12px，用 `faint-foreground`。
- 侧栏底部放账户和设置入口。
- md 以下：顶部一条 48 高的栏（☰ + 产品名），侧栏变成从左边滑出的抽屉，点导航项后自动收起。
- 主区域单独滚动。

## 页面宽度

只有三档，不允许按页面单独发明宽度：

| 档位 | 宽度 | 用于 |
| --- | --- | --- |
| `narrow` | 720 | 表单、设置、详情、长文 |
| `wide` | 1200 | 列表、看板、仪表盘 |
| `full` | 不限 | 宽表格、画布、编辑器 |

- 内容在主区域里左对齐。页面内边距 24（手机 16），顶部 24。
- 长文一行 ≤ 40 个汉字（约 680px）。

## 页头（PageHeader）

- 页面标题 22 / 600，右边放主操作（≤ 1 个主按钮，其余收进 ⋯）。
- 不写副标题，解释放进 ⓘ。
- 有层级时，返回按钮放在标题左边；面包屑最多 3 级。

## 区块

- 用 `Section`：小标题（16 / 600）+ 内容，区块之间间距 32。
- 卡片只在内容确实需要单独成组时才用（比如仪表盘上的指标）。卡片 = 1px 细线 + `rounded-lg` + 16 内边距，不加阴影，也不套卡片。

## 响应式

- 断点沿用 Tailwind：sm 640、md 768、lg 1024、xl 1280。
- 只做一套布局，靠宽度档位和断点逐级收起，不为平板或宽屏另写分支。
- 下面这些行为由组件自带：手机上弹框变成底部弹层、抽屉变成全宽、表格变成摘要列表、按钮平分一行。
- 触屏下控件自动撑到 ≥ 44（用的是 `pointer: coarse`，与宽度无关）。
- 底部固定的元素要留出安全区：`env(safe-area-inset-bottom)`。
