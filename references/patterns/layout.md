# 布局与导航

## 应用外壳（AppShell）

- 侧栏宽 240，可以收起到 56（只显示图标）。收起状态会被记住，不会因为窗口变窄自动改变。
- 侧栏用 `sunken` 底，右边一条细线。导航项高 30（触屏上 40），图标 16 + 文字 14。
- 当前项：`pressed` 填充 + 全对比文字 + 字重 500。不加竖条、不加强调色、不加描边。
- 分组标题 12px，用 `faint-foreground`。
- 侧栏底部放账户和设置入口。
- md 以下：顶部一条 48 高的栏（☰ + 产品名），侧栏变成从左边滑出的抽屉，点导航项后自动收起。
- 主区域单独滚动。

## 工作台外壳

整天开着、要在多个「地点」之间切换的工作台类产品（对话、文档、项目、表格并列），用这一套代替 AppShell。gallery「模式 · 工作台外壳」是示例。

- 宽屏（≥ 760）：rail 72 + 二级栏 264 + 主区 + inspector。
- rail：只放地点图标（21 左右）和悬停标签，当前地点用 `pressed` 填充；地点多了收进「更多」，rail 保持短；账户、设置放在底部。
- 二级栏：当前地点的分组、列表或筛选；< 1100 时收起，可以用快捷键切换；地点不需要时就没有这一栏。
- 标题栏 52 高、不透明，左边是当前对象，右边是它的操作。
- inspector：右侧的详情栏，用 `Drawer mode="dock"`。宽 360–520（默认 400），拖左边缘调整，按地点记住宽度。
- inspector ≥ 1440 时停靠成一栏，主区让出宽度、仍可点击；更窄时浮在主区上面，点外面关闭。
- inspector 里打开关联对象最多叠 3 层，第 4 层替换最上层；标题左边有「返回」；对象可以「提升」到主区打开。
- 窄屏（< 760）：rail 和二级栏变成从左边滑出的抽屉；对象用底部弹层（原生端是系统 sheet）打开，不用 inspector。
- 数值写成常量，只定义一次，别在页面里重复写数字。

## 页面宽度

只有三档，不允许按页面单独发明宽度：

| 档位 | 宽度 | 用于 |
| --- | --- | --- |
| `narrow` | 720 | 表单、设置、详情、长文 |
| `wide` | 1200 | 列表、看板、仪表盘 |
| `full` | 不限 | 宽表格、画布、编辑器 |

- 内容在主区域里左对齐。页面内边距 24（手机 16），顶部 24。
- 长文一行 ≤ 40 个汉字（约 680px）。

## 页头（PageHeader）

- 页面标题 22 / 600，右边放主操作（≤ 1 个主按钮，其余收进 ⋯）。
- 不写副标题，解释放进 ⓘ。
- 有层级时，返回按钮放在标题左边；面包屑最多 3 级。

## 区块

- 用 `Section`：小标题（16 / 600）+ 内容，区块之间间距 32。
- 卡片只在内容确实需要单独成组时才用（比如仪表盘上的指标）。卡片 = 1px 细线 + `rounded-lg` + 16 内边距，不加阴影，也不套卡片。

## 响应式

- 断点沿用 Tailwind：sm 640、md 768、lg 1024、xl 1280。
- 只做一套布局，靠宽度档位和断点逐级收起，不为平板或宽屏另写分支。
- 下面这些行为由组件自带：手机上弹框变成底部弹层、抽屉变成全宽、表格变成摘要列表、按钮平分一行。
- 触屏下控件自动撑到 ≥ 44（用的是 `pointer: coarse`，与宽度无关）。
- 底部固定的元素要留出安全区：`env(safe-area-inset-bottom)`。
