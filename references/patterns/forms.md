# 表单

## 布局

- 单列，标签在上。只有成对出现的短字段（起止日期、两个短下拉框）才并排放两列，手机上恢复单列。
- 字段间距 16，分组间距 32；分组用一个小标题（`text-heading`），不用卡片包起来。
- 表单最宽 480。独立的表单页用 narrow（720）页宽。
- 操作按钮放在表单末尾、靠右：「取消」在左，主按钮在右。弹框里的表单，按钮放在 DialogFooter。

## 字段

- 每个字段都要有标签。占位文字只用来举例（「例如 name@example.com」）。
- 必填项在标签后加红色 `*`。如果一个表单里大部分字段都是选填，改成只给必填项标 `*`，或者把选填字段挪到「更多选项」里。
- 字段下方最多一行说明；更长的解释放进 ⓘ。
- 尽量给默认值，能推断出来的就不让用户填。
- 筛选表单和查看模式下不标 `*`。
- 查看模式用只读输入框，或者用 `DetailList`，文字保持全对比，可以复制。

## 校验

- 离开字段时校验格式；用户改正后立即清掉错误；提交时校验全部字段。
- 提交失败时，把焦点移到第一个出错的字段。
- 错误信息说清怎么改：写「邮箱格式不对，例如 name@example.com」，不写「格式错误」。
- 服务端返回的业务错误：属于某个字段的，显示在那个字段下面；不属于某个字段的，显示在表单顶部，用 `destructive-subtle` 底。如果表单在弹框里，弹框不关。

## 提交

- 提交按钮在请求期间显示加载并禁用，防止重复提交。
- 编辑表单在没有任何改动时，禁用「保存修改」。
- 成功后：在弹框里的，关闭弹框；在独立页的，跳回列表或者停在原地。结果看得见就不再提示。
- 弹框里的表单，按回车可以提交（用 `<form>` 包起来）。

## 选择控件

| 选项数 | 控件 |
| --- | --- |
| 2–4，切换视图 | Segmented |
| 2–5，表单里单选，并且希望一眼看到全部选项 | RadioGroup |
| ≤ 8 | Select |
| > 8，或者需要搜索 | Combobox |
| 是 / 否，立即生效 | Switch |
| 是 / 否，点保存才生效；多选 | Checkbox |
| 筛选里的布尔值 | FilterBoolean（全部 / 是 / 否） |
