# 列表与 CRUD

gallery 的「模式 · 列表与 CRUD」页是一个可以直接照抄的完整实现：`gallery/src/gallery/pages/crud.tsx`。

## 页面结构

```
Page width="full" fill
├─ PageHeader：标题 + 主操作（新建）
├─ FilterBar：搜索 + ≤ 4 个筛选 + 「清除」
└─ DataTable：铺满剩余高度，在内部滚动；页面本身不滚动
   ├─ 表头吸顶；名称列固定在左，操作列固定在右
   └─ 底部：共 N 条 / 已选 N 项 + 批量操作；每页条数；翻页
```

- 页面要铺满高度：`AppShell` 的主区域是一个可滚动容器，路由外层加 `h-full`，`Page` 加 `fill`。表格的父容器设 `flex-1 min-h-0`。
- 表格贴着页面边缘（`-mx-6`），上方用一条细线跟筛选栏分开。

## 操作的落点

| 操作 | 落点 |
| --- | --- |
| 查看 | 点击行、或在行上按回车 → 右侧 Drawer（md），`DetailList` 展示；当前行高亮 |
| 编辑 | 行上的铅笔（悬停时出现，触屏上常驻）、⋯ 菜单、抽屉头部 → **同一个抽屉切到编辑态，原位编辑** |
| 新建 | 页头主按钮 → 同一个抽屉的编辑态，值为空；创建后切到新记录的查看态 + `notify.success`（新行可能被排序或筛选藏起来） |
| 归档、隐藏 | ⋯ 菜单、批量操作 → 立即执行 + 撤销 |
| 删除 | ⋯ 菜单最后一项、抽屉头部 → ConfirmDialog（danger）；删除后如果抽屉开着，就关掉 |
| 批量 | 勾选后，底部出现「已选 N 项」和批量按钮 |

- 查看、编辑、新建共用一个抽屉、一套布局（`DetailList` 的 `editing`）：每行至少一个控件高，值的文字起点和输入框里文字的起点对齐，切到编辑时标签和值都不挪位置，只是值变成可编辑。只读的行（编号、更新时间、进度）在编辑态保持原样。
- 编辑态：标题不变，头部操作隐藏，底部出现「取消」「保存修改」（新建时是「创建项目」）。取消回到查看态（新建时关闭抽屉），有改动时先确认；保存后回到查看态，结果就是提示，不再弹 Toast。
- 不在表格行内编辑整条记录，不做双击编辑。
- 改单个值可以用 Popover（例如改状态）。
- 关键操作不能只在悬停时出现：铅笔是个快捷方式，同样的操作在 ⋯ 菜单和抽屉里都有。

## 表格规格

- 表头 36、行 44（紧凑模式 32、36）。只有行之间的细线，不画竖线，不加斑马纹。
- 表头用 `sunken` 底、次要文字色、13px、字重 500。可排序的列在悬停时显示 ⇅，排序后显示 ↑ 或 ↓。
- 文字左对齐；数字和金额右对齐，用等宽数字。日期用短格式（「10月31日 09:00」）。
- 不换行，超长截断，悬停显示全文（单元格的值是字符串时，自动加 `title`）。
- 默认 ≤ 6 列，用 `hideBelow` 逐级隐藏次要列；md 以下整个表格变成两行的摘要列表。
- 行操作：露出来的 ≤ 2 个图标按钮，其余收进 ⋯；危险项放在菜单最后。
- 状态列用 Badge，或者用 StatusDot。

## 分页、排序、数据

- 分页而不是无限滚动（信息流除外）。每页 20 / 50 / 100 条，用 `pageSizeKey` 按表格记住选择。
- 筛选、搜索或排序变化时，回到第 1 页并清空勾选。
- 当前页的数据被删光（比如删掉第 2 页唯一的一行），表格会自动退回上一页。
- 服务端分页时传 `pagination` 和 `sorting.manual`；数据量小（< 500 条）时可以交给客户端。
- 页码从 0 开始，只在界面上显示成从 1 开始。

## 状态

`DataTable` 内置了五种状态：

- `loading` 且没有数据时：300ms 前留白，之后出骨架行。
- `loading` 且有数据时：保留数据，降低透明度。
- `error` 且没有数据时：出错状态加「重试」。
- `forbidden`：无权限。
- 没有数据时：传了 `filtered` 显示「无匹配」，否则显示「空」（可以用 `empty` 自定义标题、说明和操作）。

## 手机

- md 以下的摘要列表：每行显示标题（`mobile: "title"`）和一行元信息（`mobile: "meta"`，用 · 分隔），右侧放操作。
- 需要特殊排版时，传 `renderMobileRow`。
- 页头的主按钮保留；筛选项换行排列；搜索框占满一行。
