# 弹层

## 选择

| 场景 | 用 | 不用 |
| --- | --- | --- |
| 列表里的对象：查看、编辑、新建 | 同一个 Drawer md，原位编辑（见 `list-crud.md`） | 查看用抽屉、编辑另开 Dialog |
| 不属于某个列表对象的短任务（重命名文件、邀请成员、新建标签） | Dialog md | 整页跳转 |
| 字段很多、需要分组的编辑 | 独立的编辑页，或 Drawer lg 分区 | 抽屉里套 Tabs |
| 筛选项太多，筛选栏放不下 | Drawer sm 或 Popover | 弹框 |
| 删除、清空、发送、付款 | ConfirmDialog | 原生 `confirm()` |
| 归档、移出、隐藏 | 直接执行，然后 `notify.undo` | 确认框 |
| 触屏上的操作列表、短选项 | BottomSheet | 居中弹框 |
| 改一个值、选日期、选颜色 | Popover | Dialog |
| 一组命令 | DropdownMenu | 一排按钮 |
| 桌面工具、密集列表里的右键 | ContextMenu，和 ⋯ 菜单同一组项 | 只放在右键里的操作 |
| 浮层要出现在画布、3D 视图里的一个点 | Popover + PopoverAnchor | 手写绝对定位的浮层 |
| 工作台里边看列表边看对象（主区要保持可点） | Drawer `mode="dock"`（inspector，见 `layout.md`「工作台外壳」） | 模态抽屉 |
| 全局搜索、跳转、执行命令 | CommandPalette（⌘K） | 页面里的搜索框兼做跳转 |

## 尺寸

| 弹层 | 宽 | 高 |
| --- | --- | --- |
| ConfirmDialog | 400 | 随内容 |
| Dialog sm / md / lg / xl | 400 / 480 / 640 / min(90vw, 1200) | ≤ 85dvh；xl 固定 85dvh |
| Dialog `fixed`（md / lg） | 480 / 640 | 固定 560 / 640，≤ 85dvh；手机 92dvh |
| Drawer sm / md / lg | 400 / 560 / min(60vw, 960) | 全高 |
| Drawer `mode="dock"` | 360–520，默认 400，可拖 | 全高（停靠时是主区旁的一栏） |
| CommandPalette | 640 | 固定 480，距顶部 120；手机全宽、贴顶、≤ 60dvh |
| BottomSheet | 全宽，最宽 640 | 随内容，≤ 92dvh；列表用 [0.6, 1] 两档 |
| Popover | 288（可调） | 随内容 |
| 手机（< 640） | Dialog 变成底部弹层，Drawer 变成全宽 | |

## 结构

- Dialog：标题 → 内容（可滚动）→ 底部按钮。
  - 底部按钮靠右，次要在左、主按钮在最右。
  - 主按钮写动词（「保存修改」「创建项目」）。
  - 只有标题不够说明时，才在标题下加一行说明。
- Drawer：标题和元信息 → ≤ 2 个图标操作 → ✕；内容用 `DetailList`。
  - 查看态不放主按钮；编辑态底部是「取消」「保存修改」。筛选抽屉底部可以有「应用」。
  - 编辑在抽屉里原位进行，不再另开 Dialog。
- ConfirmDialog：标题是问句 → 一行说后果 → 「取消」+ 重复动词的确认按钮。
- 弹框里会切换标签、筛选列表、分步填写时，加 `fixed`：高度固定，只有内容区滚动，框不随内容忽大忽小。sm 仍随内容，xl 本来就固定。
- 项目可以有自己的固定尺寸（例如 420 / 560×600 / 760×640 / 960×680），写进项目的 `docs/DESIGN.md` 例外；规则不变：框固定，内容区滚动。
- Drawer `mode="dock"`：不模态、没有遮罩、不锁滚动；停靠时打开不抢焦点，点主区不关闭；浮起时点外面关闭。Esc 先关最上层。
- CommandPalette：唯一一个顶部对齐的弹框。分组有标题；每项是动词或地点，可带图标、提示和快捷键；选中后关闭并执行。只做搜索和跳转，不放表单；需要输入的命令另开弹框。

## 嵌入页（iframe）

插件、扩展这类嵌在宿主里的页面，iframe 里画的弹层盖不住宿主，所以：

- 确认框和 Toast 交给宿主画：通过桥接调用宿主的 confirm / notify（例如 `host.confirm({ title, body, confirmLabel, tone }) → Promise<boolean>`、`host.notify({ kind, text, action })`）。遮罩、焦点、Esc、原生端的系统 Alert 都和宿主一致。
- 大块的对象视图（详情、编辑）由嵌入页自己画，用同一套 kit（Drawer / Dialog / StateView），宽度沿用 inspector 的 360–520。
- 一次 Esc 只关一层：嵌入页的弹层处理了 Esc 就不再冒泡给宿主；没有弹层时才交给宿主。
- 页头只有一层：标题和主操作交给宿主的标题栏画，嵌入页不再画第二层页头；对象关闭后宿主标题还原。
- 握手有超时：10 秒内没连上宿主就显示「加载失败」+「重试」，不一直转圈。
- 字号、圆角、阴影、深色模式都跟宿主的主题走，不写任意值；深色由根元素的类切换，不跟系统外观。

## 关闭

- Esc、点遮罩、点 ✕ 都能关闭。触屏上下拉底部弹层也能关闭。
- 有未保存的输入时（传 `dirty`），任何关闭方式都先问「放弃未保存的修改？」，两个按钮是「继续编辑」和「放弃修改」。
- 保存成功后由代码直接关闭，不经过上面的询问。
- 关闭后焦点回到触发按钮。

## 叠放

- 抽屉上面可以开 Dialog，Dialog 上面可以开 ConfirmDialog。别的组合都不行：不能抽屉叠抽屉，也不能 Dialog 叠 Dialog。
- 只有最底下那层有遮罩，主题 CSS 会自动处理。
- 遮罩不模糊。

## 不要

- 手写 `fixed inset-0` 遮罩。用 `alert()`、`confirm()`、`prompt()`。
- 打开弹框后自动开始倒计时或自动关闭。
- 关闭按钮只出现在悬停时。
- 弹框里滚动整个弹框（只有内容区滚动）。
