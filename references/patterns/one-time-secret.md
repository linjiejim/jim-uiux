# 一次性密钥

API Key、Webhook 签名密钥、恢复码这类只在创建时显示一次的值。

- 创建成功后，在原位置（弹框或抽屉里）显示一个 callout：一行说明「只显示这一次，关闭后无法再查看」+ 密钥本身 + 「复制」按钮。
- callout 用 `warning` 色调（需要你处理），密钥用等宽字体、可以整段选中，不折行截断。
- 「复制」点了以后按钮短暂变成「已复制」，不另弹 Toast。
- 关闭前不强制确认；但关闭后列表里只显示名称、前缀和创建时间（如 `gh_…a1b2`），没有「查看」。
- 丢了就重新生成：列表行的 ⋯ 里有「重新生成」，走 ConfirmDialog（旧密钥会立即失效）。
- 不把密钥写进 URL、日志、Toast 或通知。
