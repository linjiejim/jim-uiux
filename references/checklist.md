# 交付自检

交付 UI 改动前，逐条检查。不适用的跳过，但要知道自己为什么跳过。

## 自动检查

- [ ] `npx vitest run tests/design`（守卫）通过；新加的 `design-allow` 都写了原因。
- [ ] 类型检查、lint、项目自己的测试都通过。

## 看一遍

- [ ] 浅色、深色各截一张图；深色模式下没有「白色孤岛」。
- [ ] 手机宽度（375）截一张图：没有横向滚动，弹框从底部升起，表格变成了列表。
- [ ] 用「紧凑」密度和「减少动态效果」各看一眼（只针对改到的区域）。

## 状态

- [ ] 加载中、空、无匹配、无权限、出错，每种都能出现，而且长得不一样。
- [ ] 加载中不会闪出「空」，失败也不会显示成「空」。
- [ ] 按钮在请求期间禁用并显示加载；重复点击不会发两次请求。
- [ ] 长文本、超长的名字、0 和非常大的数字都不会撑破布局。

## 交互

- [ ] 只用键盘就能走完：Tab 的顺序合理，焦点看得见，Esc 能关闭弹层，回车能提交表单。
- [ ] 图标按钮都有 `label`；表单控件都有标签。
- [ ] 改了内容的弹框，关闭前会先确认。
- [ ] 可逆操作有撤销，不可逆操作有确认。
- [ ] 关键操作不只出现在悬停时。

## 克制

- [ ] 一个区域只有一个主按钮；按钮写的是动词加对象。
- [ ] 没有副标题解释句，没有卡片套卡片，没有装饰性动画。
- [ ] 表格 ≤ 6 列，筛选 ≤ 4 个，每页最多一个横幅。
- [ ] 没有新的颜色、字号、圆角或阴影。真的需要时，先改主题，并补上 gallery 示例。
- [ ] 文案过一遍 `content.md`：没有「确定」，没有错误码，没有感叹号。
